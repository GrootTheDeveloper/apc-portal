# Task Briefs — Phiếu giao việc chi tiết

Mỗi task trong bản kế hoạch (`APC-Portal-Ke-hoach-cong-viec.xlsx`) chỉ ghi mức tóm tắt.
Thư mục này chứa **phiếu giao việc chi tiết** để thành viên mở ra là biết: sửa file nào,
chạy lệnh gì, xong nghĩa là gì và kiểm tra ra sao.

| File | Nội dung |
| --- | --- |
| [phase-0-starters.md](./phase-0-starters.md) | 3 task khởi động không phụ thuộc: CT1, IN1, FE1 |

## Quy ước một phiếu giao việc

Mỗi task có 7 mục cố định:

1. **Mục tiêu** — một câu: xong task này thì có gì.
2. **Bối cảnh** — hiện trạng repo, file liên quan.
3. **Các bước** — thao tác cụ thể, có lệnh và đường dẫn file.
4. **Định nghĩa Hoàn thành (DoD)** — checklist nghiệm thu.
5. **Cách kiểm tra** — lệnh/thao tác để tự xác minh trước khi mở PR.
6. **Docs liên quan** — tài liệu nguồn sự thật cần bám.
7. **Nhánh & PR** — tên nhánh gợi ý, ghi chú khi mở PR.

Khi bắt đầu một task chưa có phiếu, copy khung 7 mục này và điền.
